42 C Piscine - C00



This repository contains my solutions for the C00 project of the 42 Kocaeli C Piscine.



About the Project

The C00 project introduces the basics of the C programming language at 42. It focuses on fundamental concepts such as basic output functions (write), character and integer manipulation, looping structures, and basic conditional statements while strictly adhering to the Norm coding standards.



Exercises

- Ex00: Displays the character passed as a parameter (ft_putchar.c)

- Ex01: Displays the alphabet in lowercase (ft_print_alphabet.c)

- Ex02: Displays the alphabet in reverse order (ft_print_reverse_alphabet.c)

- Ex03: Displays all digits in ascending order (ft_print_numbers.c)

- Ex04: Tests if a number is negative or positive (ft_is_negative.c)

- Ex05: Displays all combinations of three different digits (ft_print_comb.c)

- Ex06: Displays all combinations of two numbers between 0 and 99 (ft_print_comb2.c)

- Ex07: Displays a number (given as an int) on the screen (ft_putnbr.c)

- Ex08: Displays all different combinations of n digits (ft_print_combn.c)



Technologies & Rules

- Language: C

- Compiler: gcc (with -Wall -Wextra -Werror flags)

- Standard: 42 Norm (Norminette compliant)
